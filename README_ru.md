 # RedPandaIDE
Более быстрый и мощный IDE, модифицированный на основе [Red Panda C++]（https://github.com/royqh1979/RedPanda-CPP/.
 ### Введение
RedPandaIDE является перераспределенной версией Red Panda CPP. Он сохраняет характеристики небольшого размера, всеобъемлющих функций и быстрой скорости оригинальной программы.
В этой версии мы украшаем интерфейс пользователя и добавляем различные современные элементы IDE, такие как расширения и встроенные терминалы; Добавлена поддержка последнего стандартного синтаксиса C++ и последних исправлений ошибок.
 ### Целевой пользователь и использование для RedPandaIDE
 - OIers
 - Разработчики микроконтроллеров
 - Разработчики малых проектов
Быстро проверять идеи
 - Быстрое просмотрение кода

### Начать
 ### (i) Нет версии компилятора
1. Скачать последнюю версию программного обеспечения
2. Установить
3. Скачать компилятор в Extension Manager или Импортировать существующий компилятор C++
4. Начните использовать
 ### (ii) С версией компилятора
1. Скачать последнюю версию программного обеспечения
2. Установить
3. Начните использовать

### Почему не использовать Dev-C++?  (Для IOers)
 - Отладчик нестабильен
 - Интерфейс rudimentary
 - Почти никаких кодовых запросов 
 - Компилятор C++ устарел и несовместим с конкурентной средой

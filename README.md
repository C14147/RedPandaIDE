# RedPandaIDE 
A Faster and More Powerful IDE modified based on [Red Panda C++](https://github.com/royqh1979/RedPanda-CPP/).

### Introduction
RedPandaIDE is a redistribution version of Red Panda CPP. It retains the characteristics of small size, comprehensive functions, and fast speed of the original program.

### Core Objective
- Code quality 
- Modern UI
- New features (such as extensions, built-in terminals)

### Editions
- Pure-Editor Edition (Editor Only)
- OIer Edition (OJ Problem Set, Comparison Tester, etc.)
- Complete Edition (Extensions, Themes, Plugins, etc.)

### Supported Platforms
- Windows 10 or later
- Linux

### Planned Features
- Extensions
- Modern UI
- Built-in terminal

### The Target User & Usage For RedPandaIDE
- OIers
- Microcontroller developers
- Small projects developers
- Quickly validate ideas
- Quickly view code

### Why not use Dev-C++ ?
- The debugger is unstable
- The interface is rudimentary
- Almost no code prompts
- The C++ Compiler is outdated and inconsistent with the competition environment
